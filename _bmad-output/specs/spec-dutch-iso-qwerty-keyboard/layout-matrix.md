# Dutch ISO QWERTY Layout Matrix

The Dutch keyboard guidance must expose these physical rows from left to right.

| Row | Keys |
| --- | --- |
| Number | §, 1, 2 (€), 3, 4, 5, 6, 7, 8, 9, 0, -, = |
| Top letter | Q, W, E, R, T, Y, U, I, O, P, [, ] |
| Home | A, S, D, F, G, H, J, K, L, ;, ', \\ |
| Bottom | backtick, Z, X, C, V, B, N, M, ,, ., / |

## Shifted key matrix

The table below shows the output when Shift is held, in the same physical
left-to-right order as the base layout.

| Row | Shifted keys |
| --- | --- |
| Number | ±, !, @, #, $, %, ^, &, *, (, ), _, + |
| Top letter | Q, W, E, R, T, Y, U, I, O, P, {, } |
| Home | A, S, D, F, G, H, J, K, L, :, ", \| |
| Bottom | ~, Z, X, C, V, B, N, M, <, >, ? |

## Mapping expectations

- Uppercase letters resolve to their lowercase physical keys and require Shift.
- Finger guidance follows the physical key position, including the ISO extra key and the bottom-row backtick.
- The space bar remains available as the thumb key.
